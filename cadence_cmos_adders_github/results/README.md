# Results and Simulation Evidence

This directory is reserved for derived project results and reports.

The current repository keeps the supplied waveform screenshots under `../screenshots/simulation/` because those images are the original available evidence.

No numerical performance results have been added because the supplied screenshots do not provide enough reliable information to extract and report exact delay, power, energy, area, or similar measurements.

If original simulation result databases or measurement reports are recovered later, they can be added here with clear provenance and measurement definitions.
